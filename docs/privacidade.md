# Política de privacidade

O **Agendador de Shorts** roda no computador do próprio autor e só acessa as contas dele.

- **Dados usados:** identificador e nome da conta, para confirmar o login, e os vídeos, títulos e descrições que o autor escolhe publicar. No YouTube, também lê views, likes e comentários dos próprios vídeos para o painel de desempenho.
- **Onde ficam:** os tokens de acesso ficam no computador do autor (Keychain do macOS ou arquivo local protegido) e nunca são enviados a terceiros.
- **Compartilhamento:** nenhum dado é vendido ou repassado. Os títulos dos vídeos passam por um modelo de IA próprio (Mangaba) para escolher horário e hashtags.
- **Remoção:** o titular pode revogar o acesso a qualquer momento nas configurações de cada rede. Os tokens locais são apagados junto.
